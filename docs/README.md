# Documentacao

## Estrutura

- `backend/`: validacao de entrada, rate limiting e observabilidade da API.
- `frontend/`: politica de sessao e armazenamento seguro do aplicativo Flutter.
- `operations/`: scripts de backup, restore e procedimentos operacionais.
- `BACKUP_RESTORE.md`: politica de recuperacao e RPO/RTO.
- `BANCO_PERFORMANCE.md`: indices, consultas e metas de performance.
- `INFRAESTRUTURA.md`: deploy, probes, carga e requisitos de ambiente.
- `RELEASE_CHECKLIST.md`: checklist de release.
- `RELEASE_GOVERNANCE.md`: gates, aprovacao e rollback.
